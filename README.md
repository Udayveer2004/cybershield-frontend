# CyberShield  
Real-Time URL Threat Intelligence System

## Project Overview
CyberShield is a machine learning-based web application designed to detect malicious URLs in real-time. The system analyzes URL patterns and classifies them as Safe or Malicious with a confidence score.

## Features
- Real-time URL analysis
- ML-based classification
- Confidence score visualization
- Clean and responsive UI
- Production deployment using Vercel

## Tech Stack
- Next.js
- JavaScript
- CSS
- REST API Integration
- Vercel Deployment

## Deployment
The application is deployed on Vercel for production-level hosting and scalability.
